## Saved Predictions

The repository tracks 178 per-pair prediction files. They preserve the model decisions and operational measurements used to calculate the reported results.

Prediction records contain fields such as:

```json
{
  "source_id": "AAH-101",
  "target_id": "AAH-504",
  "label": 1,
  "prediction": 1,
  "raw_response": "{\"is_linked\": true}",
  "latency_ms": 984.2,
  "input_tokens": 372,
  "generated_tokens": 7,
  "truncated": false
}
```

The exact schema varies slightly by method because local, RAG, LoRA, and cloud-batch runs log different operational metadata.

## Statistical JSONs

### `significance_tests_clean_f2.json`

Generated by `SCRIPT/10_significance_tests.py`. It compares the main local methods using per-project clean macro F2 across eight projects.

Current key comparison:

- Combined LoRA+RAG vs RAG-B: mean delta = 0.0069, wins = 5/8, sign-test p = 0.7266, Wilcoxon p = 1.0000, bootstrap 95% CI = [-0.0102, 0.0309].

Interpretation: the combined method has the highest absolute macro F2, but the project-level evidence does not support a statistically robust advantage over RAG-B alone.

### `stratified_by_link_type_v3.json`

Generated by `SCRIPT/9.stratified_eval_by_link_type.py`. It reports performance separately for:

- `refinement`: Parent -> Standard links
- `subtask`: Standard -> Child links

This file supports the link-type analysis in the thesis.
